JavaScript Frameworks

How modern tools like React, Angular, Vue and Svelte changed the way interactive websites are built, and what every new web developer should understand about them.

Abstract

A JavaScript framework is a collection of pre-written code and conventions that gives developers a structure for building the interactive part of a website or web application.

Early websites updated the page by reloading it from the server, and later by changing pieces of the page directly with libraries such as jQuery. As web applications grew to the size of desktop software, that approach became hard to maintain. Frameworks solved this by organizing the interface into reusable components and by keeping the screen automatically in sync with the application's state.

This site traces how frameworks evolved, compares the four most widely used options today, and explains the core ideas they share. The goal is to help a beginner understand what a framework does for them and how to choose one for a project.

Key Terms

Framework
Code that provides the structure of an app and calls your code.
Library
Code that you call when you need it, such as jQuery.
Component
A self-contained, reusable piece of the user interface.
DOM
The browser's tree of objects that represents the page.
Single-Page Application (SPA)
An app that loads once and updates the view without full reloads.
State
The data an app holds at a given moment that drives what is shown.
