Topic 01

The Evolution of Frameworks

Why developers stopped writing every page update by hand, and how that led to the component-based tools used today.

The Static Web (1990s)

The first websites were collections of HTML documents. Every click on a link asked the server for an entirely new page. JavaScript, created by Brendan Eich at Netscape in 1995, was first used for small effects such as checking a form field before it was submitted.

Ajax and jQuery (2005–2010)

In 2005 the term Ajax described a technique where the browser requests data in the background and updates only part of the page. Applications like Gmail and Google Maps showed that a website could feel like a desktop program.

Writing that code was difficult because browsers behaved differently. jQuery, released in 2006, hid those differences behind a short, friendly syntax and quickly became the most used JavaScript library on the web. A typical jQuery update looked like this:

$("#cart-count").text(items.length);

The developer had to remember every place on the page that displayed the cart count and update each one manually. In a large app, missing a single update meant the screen showed the wrong information.

The First Frameworks (2010–2013)

A wave of frameworks borrowed the Model–View–Controller (MVC) pattern from server-side programming to separate data from presentation:

  • Backbone.js (2010) added models and collections to organize data.
  • AngularJS (2010, Google) introduced two-way data binding, so the page and the data updated each other automatically.
  • Ember.js (2011) focused on strong conventions for large, ambitious applications.

The Component Era (2013–today)

In 2013 Facebook released React, which treated the user interface as a tree of small, reusable components. Instead of telling the browser how to change the page, a developer describes what the page should look like for the current data, and React works out the changes. Vue (2014), Angular (a complete rewrite of AngularJS, 2016) and Svelte (2016) all adopted the component model.

Milestone timeline

  1. 1995 JavaScript is created at Netscape.
  2. 2005 “Ajax” popularizes background data requests.
  3. 2006 jQuery is released.
  4. 2010 Backbone.js and AngularJS appear.
  5. 2013 React is open-sourced by Facebook.
  6. 2014 Vue.js is released by Evan You.
  7. 2016 Angular 2 and Svelte are released.
  8. 2020s Meta-frameworks such as Next.js and Nuxt add server rendering.

How the Approach Changed

Table 1. Three generations of front-end development
Era Main tool How the page updates Main drawback
Static web HTML + server Full page reload Slow, not interactive
Ajax / jQuery jQuery Developer edits the DOM by hand Hard to keep large apps consistent
Components React, Vue, Angular, Svelte Framework updates the DOM from state Learning curve and build tooling

Takeaway: each step moved more of the repetitive work from the developer to the tool, so developers could focus on what the application should do.
