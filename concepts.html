Key Concepts

Seven Ideas Behind Every Framework

The names and syntax differ, but React, Angular, Vue and Svelte are built on the same small set of ideas.

01 Components

A component is a self-contained piece of the interface, such as a button, a navigation bar or a product card. It bundles its own structure (HTML), appearance (CSS) and behavior (JavaScript). Components can contain other components, so a whole page becomes a tree of small, reusable parts.

02 State

State is the data a component remembers while the app runs, for example the items in a shopping cart or whether a menu is open. When state changes, the framework re-renders the parts of the page that depend on it. This is the main reason frameworks exist: the screen always matches the data.

03 Props (Inputs)

Props are values a parent component passes down to a child, much like attributes on an HTML tag. A ProductCard might receive a product name and price as props. Data flows down through props, while children send messages up through events.

04 The Virtual DOM

Changing the real browser DOM is relatively slow. React and Vue keep a lightweight copy of the page in memory called the virtual DOM. When state changes, they build a new virtual version, compare it with the old one (a process called diffing) and apply only the differences to the real page.

Svelte reaches the same goal differently: its compiler works out ahead of time exactly which lines of the page depend on which data.

05 Declarative Rendering and Data Binding

With jQuery, code is imperative: “find this element, then change its text.” Frameworks are declarative: the developer writes a template that says what the page should look like for any state, such as <p>Items: {count}</p>. Data binding keeps that template connected to the data, and two-way binding also updates the data when a user types into a form field.

06 Client-Side Routing

In a single-page application, the browser loads one HTML page and the framework swaps components in and out as the user navigates. A router maps each URL, such as /products/42, to a component and updates the address bar without a full page reload, which makes navigation feel instant.

07 Build Tools

Framework code such as JSX, TypeScript or .vue files cannot run in the browser as written. A build tool like Vite or webpack converts it into plain JavaScript, combines files into bundles, removes unused code and provides a development server that refreshes the page as you edit.
