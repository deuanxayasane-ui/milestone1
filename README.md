# JavaScript Frameworks — IT 3203 Project (Milestone 1)

A six-page informational website about JavaScript frameworks, built with HTML and one CSS file.

## Pages
- `index.html` – Homepage: title, abstract, key terms, table of contents
- `evolution.html` – Topic 1: The evolution of JavaScript frameworks
- `comparison.html` – Topic 2: Comparing React, Angular, Vue and Svelte
- `concepts.html` – Seven key concepts
- `references.html` – References and learning resources
- `about.html` – About the author and the project
- `css/styles.css` – the single stylesheet
- `images/` – SVG illustrations

## Deploying to GitHub Pages
1. Create a new public repository on GitHub (for example `it3203-project`).
2. Upload all files, keeping the folder structure (`index.html` must be at the top level).
3. In the repository, open **Settings → Pages**, set **Source** to "Deploy from a branch",
   choose the `main` branch and the `/ (root)` folder, then **Save**.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
