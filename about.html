About This Project

This website is the semester project for IT 3203 Web Development. It presents my research on JavaScript frameworks and will grow over three milestones:

  1. Milestone 1: a basic multi-page site built with HTML and CSS (this version).
  2. Milestone 2: more research content and interactive features with JavaScript.
  3. Milestone 3: final design improvements and completed research.

I chose this topic because frameworks are what most companies use to build modern web applications, and understanding them is a practical next step after learning HTML, CSS and JavaScript.

The site is hand-coded with HTML and a single CSS file and is hosted on GitHub Pages.

This website is a class project for IT 3203 Web Development at Kennesaw State University.

Course website: ksuweb.github.io/IT3203
