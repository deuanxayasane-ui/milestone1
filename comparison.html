Topic 02

Comparing the Big Four

React, Angular, Vue and Svelte all build interfaces from components, but they make different trade-offs in size, structure and learning curve.

React

React describes itself as a library for building user interfaces rather than a complete framework. It handles the view layer, and developers add other libraries for routing or data fetching. Components are written with JSX, a syntax that mixes HTML-like tags into JavaScript. Because it is the most widely used option, React has the largest collection of tutorials, packages and job listings.

Angular

Angular is a full, “batteries-included” framework. Routing, forms, HTTP requests and testing tools are all built in, and every project follows the same structure. It uses TypeScript, which adds types to JavaScript. That consistency is valuable for big teams, but it means there is more to learn before writing the first page.

Vue

Vue calls itself a progressive framework: you can add it to a single part of an existing page, or use it to build an entire application. Its templates look like regular HTML, which makes it comfortable for people who already know HTML and CSS.

Svelte

Svelte takes a different approach. It is a compiler: it turns components into small, plain JavaScript during the build, so there is no large framework running in the browser. The result is usually less code sent to the user and very fast updates.

Choosing a Framework

There is no single best framework. Questions worth asking include:

  1. Team experience: what does the team already know?
  2. Project size: a small widget and a large enterprise system have different needs.
  3. Ecosystem: are there existing packages for the features you need?
  4. Performance: does the app need to load quickly on slow phones and networks?
  5. Long-term support: is the project actively maintained?

Tip for beginners: the concepts on the Key Concepts page transfer between all four frameworks, so learning one well makes the others much easier.
